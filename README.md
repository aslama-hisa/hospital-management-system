# Hospital Management System
Project Overview:

The Hospital Management System (HMS) is a comprehensive application designed to streamline clinical workflows, enhance patient data management, and improve communication between healthcare providers and patients. It offers an intuitive interface for doctors, patients, and administrators to interact efficiently.

Objectives:

•	Allow doctors to efficiently enter, view, and manage patient records.

•	Provide a standalone cross-platform application (desktop and mobile).

•	Enable quick search of patient data by name or date.

•	Improve clinic workflows and healthcare service delivery.

System Features:

•	User Modules:

  o	Admin: Manages doctors and patients.

  o	Doctors: Access patient histories, manage appointments.

  o	Patients: Book appointments, view doctor profiles.

•	Data Management: Doctors can input and retrieve patient data easily.

•	Search Functionality: Fast search by name/date for efficient record access.

•	Accessibility: Operable in public Wi-Fi areas for mobility.

Technical Specifications:

•	Architecture: Modular design illustrated with structure charts.

•	Database: Secure and scalable (e.g., MongoDB).

•	Technologies Used:

   o	Backend: Node.js

   o	Database: MongoDB

   o	Platform: Windows 11

   o	Hardware: Minimum Intel i7, 3GB RAM

Non-Functional Requirements:

•	Usability: Simple UI for all user roles.

•	Reliability: Stable and secure data management.

•	Performance: Optimized for responsiveness and data handling.

Feasibility Study:

•	Economic: Cost-effective compared to traditional methods.

•	Operational: Practical for real-world healthcare settings.

•	Technical: Suitable technologies used to ensure system success.

Future Enhancements:
